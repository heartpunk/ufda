# Hoare logics for low-level code

The two references identified in the roadmap discussion are:

- [Saabas and Uustalu (2007)](https://doi.org/10.1016/j.tcs.2006.12.020), *A Compositional Natural Semantics and Hoare Logic for Low-Level Languages*. Zotero item `FPNRVMAQ`. It gives a compositional semantics and matching Hoare logic for a basic low-level language with jumps.
- [Lundberg et al. (2026)](https://doi.org/10.1016/j.jlamp.2025.101099), *Hoare-style logic for unstructured programs*. Zotero item `IJIR9HCT`. It presents a Hoare-style logic for unstructured programs and arbitrary control flow.

The DOI URLs are the clickable citations. The second paper's journal issue is dated March 2026; the `2025` inside its DOI is not the journal publication year.
